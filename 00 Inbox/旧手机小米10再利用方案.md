# 旧手机（小米10）再利用方案

> [!abstract] 一句话结论
> 小米10 是骁龙865 + 8/12GB 内存 + UFS3.0 的旗舰底子，**性能接近入门级迷你主机**，而且 LineageOS 至今仍在**官方维护**（umi，当前 23.2 / Android 16）。它不是电子垃圾，是「带屏幕、带电池、带 5G 和一套传感器的 ARM 小服务器 + 摄像头」。

## 一、先认清这台机器的底牌

| 项目 | 参数 | 对再利用的意义 |
|---|---|---|
| SoC | 骁龙 865（SM8250，Adreno 650） | 跑 PS2/Wii 模拟器、轻量 AI 模型、本地服务都够 |
| 内存/存储 | 8 或 12GB / 128·256GB UFS3.0 | 长时间跑后台服务不会因为内存被杀 |
| 屏幕 | 6.67" AMOLED 1080x2340 90Hz | 做常亮面板/电子书/时钟很好看，但**注意烧屏** |
| 相机 | 108MP HMX 主摄（OIS）+ 超广角 + 前置 20MP | 画质吊打百元级家用摄像头 |
| 电池 | 4780mAh + **30W 有线 / 30W 无线 / 10W 反向无线充** | 无线充 = 床头可放充电板，还能给耳机盒回充 |
| 传感器 | **红外发射器**、NFC、陀螺仪、双频 GNSS、气压无关但含霍尔 | 红外 = 万能遥控器；NFC = 门禁/标签触发 |
| 音频 | 对称双扬声器 | 当闹钟/白噪音/蓝牙音箱，音质不丢人 |
| 接口 | USB-C **USB 2.0 + OTG** | 能接硬盘/网卡，但**没有视频输出**，投屏只能无线 |

> [!warning] 两个天生的短板
> 1. **USB 2.0 无 DP Alt Mode** → 不能像三星 DeX 那样有线接显示器，做「桌面主机」的幻想要放弃；投屏只能走 Miracast / Chromecast / scrcpy（网络）。
> 2. **没有 3.5mm 耳机孔** → 当播放器要么用 USB-C DAC/转接头，要么蓝牙（支持 aptX HD）。

## 二、按投入排序的三条路线

### 路线 1️⃣ 十分钟级：装 App 就用（不刷机、不 root）

| 用途 | 推荐做法 | 说明 |
|---|---|---|
| **家庭/宠物/婴儿摄像头** | IP Webcam、Alfred、Dormi（双向对讲） | 固定支架 + 常插电 + 关屏；108MP 主摄画质远超专用摄像头 |
| **电脑摄像头 / 副屏** | DroidCam、Iriun（USB 或 Wi-Fi）；spacedesk / Weylus 变第二屏或数位板 | 网课、开会、直播推流都行 |
| **桌面时钟 / 天气 / 相框** | 数字时钟、Fotoo、日历待办类 App | 低亮度 + 深色 + 定时换位，防 AMOLED 烧屏 |
| **电子书阅读器** | Moon+ Reader、KOReader、微信读书 | 6.67" AMOLED 夜里看比 LCD 舒服，是它最被低估的用途 |
| **万能遥控器** | 「小米万能遥控」+ 红外发射器 | 空调/电视/风扇遥控集中到一台，常年插电放客厅 |
| **音乐播放器 / 床头音响** | Poweramp、UAPP + 蓝牙音箱或 USB-C DAC | 双扬声器 + 30W 无线充，直接当床头机 |
| **行车记录仪 / 车机 / 车况仪** | AutoGuard 等黑匣子类 App；Headunit Reloaded + 手机热点；ELM327 + Torque Pro | 导航专用机，不怕晒坏主力机 |
| **游戏机** | RetroArch、NetherSX2（PS2）、Dolphin（Wii/GC）+ 蓝牙手柄（8BitDo） | 865 跑 PS2/GC 是甜点区间 |
| **老人机 / 儿童机 / 备用机** | 精简桌面 + 大字模式，卸掉 SIM 或只留副卡 | 性能过剩 = 用得久 |
| **专注设备** | 只装番茄钟/白噪音，物理隔离主力机上的娱乐 | 靠「设备边界」而不是靠意志力 |

### 路线 2️⃣ 半小时级：Termux，把手机变成家用服务器（不需要 root）

```text
pkg install openssh syncthing rclone git python nodejs-lts
```

- **同步节点**：Syncthing 常驻，手机 ↔ 电脑 ↔ NAS 三向同步（配合你的 Obsidian 库很好用）。
- **定时任务**：crond 或 termux-job-scheduler 跑备份、抓取、日报脚本。
- **局域网服务**：FastAPI / Express + nginx，做家里的小 API、仪表盘、签到脚本面板。
- **下载机 / 种子机**：aria2、qBittorrent-nox。
- **网络工具箱**：nmap、tcpdump、ssh 客户端、WiFi 分析。
- **小模型玩具**：llama.cpp 跑 3B Q4（约 2GB），或用 Termux 当家里电脑上 Ollama 的移动客户端。

> [!tip] 后台保活三件套
> ① Termux 里 `termux-wake-lock`；② 设置里对 Termux 关闭电池优化、允许自启；③ 长期常驻就插电 + 限充。

### 路线 3️⃣ 一个周末级：刷 LineageOS，彻底改造

小米10 代号 **umi**，**LineageOS 官方仍在维护**，当前 23.2（Android 16 = 目前最新的版本），已有 21/22.x 历史版本可退。刷完能：
- 去掉 MIUI 广告与预装，系统干净、待机更省电；
- root（Magisk）后做真正的自动化与限充（见下）；
- 想当纯工具机/监控机时，安全更新和隐私都更可控。

流程要点：解锁 BL（小米账号绑定需等待 168 小时）→ 刷入 Recovery → 装 ROM → 可选 Magisk。刷机前**先备份，确认型号是 M2001J2G/J2I**。

> [!danger] 刷机风险自担
> 解锁会清数据、影响部分银行/支付类 App（Device integrity 检测），主力机不要随便试；这台备用机就无所谓。

## 三、长期插电必做的两件事（最重要、最容易被忽略）

> [!warning] 电池鼓包是旧手机当服务器/监控的**头号杀手**
> 满电 + 长期高温 = 鼓包。鼓包轻则顶开后盖，重则起火。

1. **限充到 60%~80%**：MIUI 里可用「充电保护/夜间充电保护」；root 后用 **AccA（Advanced Charging Controller）** 精确设到 70%。
2. **散热与摆放**：取下手机壳、别放床上/沙发/阳光直射处、不要叠在路由器上；能立起来就立起来通风。
3. **每季度体检一次**：看后盖是否翘起、屏幕是否被顶出；电池明显衰减就花几十块换一块，性价比极高。
4. **OLED 防烧屏**：常亮场景用深色主题 + 低亮度 + 息屏显示，避免长期固定白色大字/固定位置图标。

## 四、如果让我只推三个

1. **家庭摄像头 / 看护机**——10 分钟出效果，收益立竿见影，画质还比买的强。
2. **常亮家庭面板**——时钟 + 日历 + 天气（或 Home Assistant 仪表盘，配 Fully Kiosk Browser 常亮），每天都会看。
3. **Termux 家用小服务器**——Syncthing 同步节点 + 定时脚本 + 局域网 API。**顺手把 Node 后端学习计划的 S8「部署与上线」拿它当真实部署环境**，手机就是最便宜的练习服务器。

一句话：**要么把它变成一台「传感器 + 摄像头」，要么变成一台「小服务器」，别让它继续当备用机吃灰。**
