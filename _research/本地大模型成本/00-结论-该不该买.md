## 二、这台机器到底能跑什么

### 2.1 硬限制：64GB 的 GPU 只能看到约 30GiB

- Linux 默认 GTT ≈ 系统内存 50% → 64GB 机器 GPU 约 **30 GiB**（[ROCm Strix Halo 文档](https://rocm.docs.amd.com/en/docs-7.2.0/how-to/system-optimization/strixhalo.html)）
- 可用 `amdgpu.gttsize=` / `ttm.pages_limit=` 放大到 45–50GB，但系统只剩十几 GB
- **gpt-oss-120b MXFP4 权重 63.4GB —— 物理上装不下**（即使 64GB 全给 GPU 也没有 KV cache 和系统的位置）

→ **64GB 是"30B 级专用机"，128GB 才是"120B 级入门机"。这是 64 与 128 之间 ¥10,000 差价买到的唯一东西。**

### 2.2 实测速度（128GB 机型 Linux Vulkan，64GB 跑同尺寸模型速度一致）

| 模型 | 体积 | 生成 tok/s | 说明 |
|---|---:|---:|---|
| Qwen3-30B-A3B / Qwen3-Coder-30B | 13.9–17.5 GB | **100–101** | 甜点区，完全可以日常用 |
| Qwen3.6-35B-A3B | 20–22 GB | 62.6–81 | 更大更好，也还行 |
| Qwen3.8-27B dense | 17.7 GB | 12.9（MTP 22.7） | dense 被带宽锁死 |
| Llama-3.1-70B Q4 | 40–42 GB | **4.7–5.1** | 能跑，但基本没法用 |
| gpt-oss-120b | 63.4 GB | **❌ 跑不了** | 需要 128GB |

> 出处：[strix-halo-guide](https://github.com/hogeheer499-commits/strix-halo-guide)（逐条可溯源到 raw CSV）、[strix-halo-llm-speeds](https://github.com/huppiflupp/strix-halo-llm-speeds)、[visorcraft/strix-halo-llm-perf](https://github.com/visorcraft/strix-halo-llm-perf)

**带宽就是天花板**：实测约 215 GB/s，`tok/s ≈ 215 ÷ 模型体积(GB)`。这就是为什么 3B 激活的 MoE 能跑 100，而 dense 70B 只有 5。

### 2.3 好不好用：真实的坑

| 项 | 现状 |
|---|---|
| Linux | **几乎必须**。所有一手实测都在 Ubuntu/Fedora；ROCm 官方支持 gfx1151，需内核 ≥6.18.4 |
| Windows | 能跑（LM Studio 选 Vulkan），但：ROCm runtime 有**输出错误** bug（LM Studio #2310 仍未修）；>64GB 模型加载失败 bug（#1790）；息屏可能降频到 1/5 |
| vLLM | gfx1151 上基本不可用 → **没有生产级高并发 serving** |
| 微调 | bitsandbytes 4bit 有 NaN bug，只能上 dev 版 → **微调能力≈没有** |
| 图像/视频 | ComfyUI 可用但慢：Flux.2 约 10 分钟/张 |
| 功耗噪音 | **跑 LLM 整机约 120W**，36–41 dBA；空闲 12.8W。这是全机最大卖点 |
| 内存 | **焊死不可升级**，选错容量没法补救 |

对比：双 3090 主机约 700W，RTX 5090 单卡 575W。**395 每瓦性能是 3090 的 4 倍以上。**

**结论：**

## 五、2026 年的特殊背景（会改变判断）

1. **DRAM/显存涨价周期**：二手 3090 从 2025 年的 ¥5,000–6,000 涨到 ¥9,200；Beelink GTR9 Pro 官方价一年涨 119%；苹果 2026-05 已下架 Mac Studio 128GB / Mac mini 64GB 选项。**395 因板载 LPDDR5X 涨幅较小，相对性价比反而是近年最好的。**
2. **Medusa Halo（Ryzen AI MAX 500）在路上**：传闻 Zen 6 + RDNA 5 + LPDDR6、384-bit，带宽再提约 80% → 约 460GB/s，预计 2027。**现在买 395 是一代末期，明年二手价会很不好看。**
3. **国产 API 价格已经低到离谱**：DeepSeek Flash 重度用一年 ¥737，GLM-5.3-Flash ¥621，还有免费模型。这让"本地省钱"这个理由在 2026 年基本不成立。

## 六、建议

**不买 64GB，如果：**
- 你只是"每天用 AI 干活" → 订阅 + API 兜底，¥500–5,000/年，模型质量高 1–2 档
- 你想跑 gpt-oss-120b / 120B 级 → 直接 128GB（¥22,999）
- 你要微调 / vLLM / 图像生成 → 3090/5090（CUDA）
- 你每周只用几小时 → 云 GPU 按时租

**可以买 64GB，如果（三条全中）：**
1. 主力模型就是 30B 级 MoE（Qwen3-30B-A3B / Qwen3-Coder-30B）
2. 你不需要 100B+ 模型，也不需要微调
3. 你愿意装 Linux 折腾，并且看重 **120W 静音常开**（家庭 AI 服务器、RAG、自动化、隐私数据）

**替代方案：等到 2027 年 Medusa Halo，或者直接上 128GB。**
